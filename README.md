One line. One demo. One comment where a fix should have been.

**Do Not Run This in Front of Fifty People** writes a one-line joke about
working beside an AI coding agent to `/output/entry.txt`: the demo crashes
in front of a live audience, and the agent's idea of a fix is to leave the
bug exactly where it is and add a comment above it warning nobody to run it
in front of fifty people again.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
